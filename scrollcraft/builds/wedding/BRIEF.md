# 모바일 청첩장 디자인 기록
사용자 제공 제약과 일상적인 구현 판단으로 작성. 별도 인터뷰 없음.
- 목적/대상: 결혼 소식을 전하고 하객에게 일시, 위치, 계좌 안내.
- 분위기: 차분한 명조, 흰 바탕, 올리브 포인트 한 색. 사용자 지정.
- 순서: 메인 사진 → 이름 → 인사말 → 일시 → 장소 → 갤러리 → 계좌. 사용자 지정.
- 에너지: 조용한 시작, 갤러리에서 사진을 충분히 감상, 감사로 마무리.
- 감정 곡선: 친근함(메인 사진), 설렘(이름), 따뜻함(인사), 기대(날짜), 안심(교통), 기쁨(사진), 감사(마음).
- 기억할 장면: 우리의 일상이 한 장씩 이어지는 사진 앨범.
- 미감/세계: editorial letter, 별도 장면. 영상/3D보다 사용자 사진과 읽기 편한 단일 열이 적합.
- 자산: 사용자 제공 사진 5장. 생성 이미지 없음.
- signature: 날짜 구역 진입 시 두 이름 사이의 선과 날짜 아래 밑줄이 이어지는 ‘함께하는 날’ 모션.
- 구조: 사진 포스터 → 여백의 이름 → 편지 → 달력 → 정보 안내 → 비대칭 앨범 → 계좌와 감사.
- 모션: 날짜 선, 섹션 짧은 등장, 사진 hover, 대화상자 확대. native CSS/IntersectionObserver.
- 예외: 사용자 단순 HTML/CSS/JS 및 외부 라이브러리 금지 우선. scrollcraft 런타임/영상 생성/핀 스크롤 도입 안 함.
- 중간 공백은 문단과 섹션을 구분하기 위한 여백이며 빈 스크롤 구역 없음.
- 디자인 다이얼: DESIGN_VARIANCE 5 / MOTION_INTENSITY 3 / VISUAL_DENSITY 3.
- fingerprint: 신규 프로젝트여서 기존 비교 행 없음.
